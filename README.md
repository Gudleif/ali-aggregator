# PC Ali Aggregator

Проект-агрегатор для автоматизации работы с партнерскими сетям, построенный на базе Django и упакованный в Docker.

## Основной функционал
*   **Django Backend**: Управление бизнес-логикой и структурой данных.
*   **Интеграция с партнерскими сетями**: Автоматизированная обработка данных через CSV-файлы для партнерского маркетинга.
*   **Dockerize**: Полная контейнеризация проекта для быстрого развертывания и изоляции окружения.
*   **Безопасность**: Использование переменных окружения (.env) для хранения конфиденциальных данных.

## Технологический стек
*   Python 3.x
*   Django
*   Django REST Framework
*   PostgreSQL
*   Docker & Docker Compose

# PC Ali Aggregator

An aggregator project designed to automate affiliate network management, built on Django and containerized with Docker.

## Key Features
*   **Django Backend**: Managing business logic and data structures.
*   **Affiliate Network Integration**: Automated data processing via CSV files for affiliate marketing.
*   **Dockerization**: Full project containerization for rapid deployment and environment isolation.
*   **Security**: Using environment variables (.env) to store sensitive data.

## Tech Stack
*   Python 3.x
*   Django
*   Django REST Framework
*   PostgreSQL
*   Docker & Docker Compose
